FOUNDRY · REDESIGN 3

Dense pro-dashboard. Built for the operator who watches three children, a budget and a plan at once. The transcript becomes a tabular log grid (row number, time, source, summary, cost, state) with a sticky header; the agent rail is always on instead of hiding behind a tab; a one-line status ticker absorbs model, mode, spend, budget ratio, agent state counts, queue depth and routing — the strip that used to take a whole row now takes one and says more. Colour is rationed: graphite everywhere, lime only for you/focus, and semantic hues only for state. Every state is a glyph and a word.

Implementation notes (Textual / TCSS)

  • The log is a real grid. DataTable (or a ListView of rows with fixed-width cells) gives the sticky header, zebra striping, row selection and ⏎ expand for free. Columns: #4 · TIME 7 · SOURCE 7 · SUMMARY flex · COST 8 · ST 3. SUMMARY wraps with a hanging indent; COST/ST are right/centre aligned with tabular numerals.
  • ROLE → SOURCE mapping is lossless but shorter so the column fits 7 cells: YOU→YOU · LEAD→LEAD · AGENT n→A1/A2/A3 · TASK→TASK · TOOL ▸ title→ A1 + “▸ title” · ERROR→ERROR · APPROVAL REQUIRED→APPR · RECEIPT→RCP. The full word is always restored in the expanded row and in the ^O pager.
  • Agent rail is promoted out of the tab set into a permanent middle pane (the tab still exists for the detail table). This is the single biggest density win: operators never lose sight of the ≤3-concurrent / ≤2-child invariants.
  • The ticker replaces the status strip and absorbs route + queue + exclusion count. It is one Static with width: 1fr; overflow: hidden; fields are dropped right-to-left as width shrinks (route and EXCL go first), then it wraps to two rows below 100 columns.
  • Approval is a banner, not a card. One inverted row ($approval foreground on dark text — the only place in FOUNDRY where colour fills a whole line) plus an action dock. It spans all three panes so it reads as a run-level gate.
  • Narrow mode: .railp, .insp { display: none }; a pane switcher (LOG / AGENTS / PLAN / ROUTE / BUDGET) takes their place, the log drops the #, COST and ST columns, and the ticker wraps to two rows.
  • Contrast: text on background is 13.9:1, textMuted 5.6:1, textFaint 3.4:1 — textFaint is therefore only ever used on non-essential metadata (never on state or cost). Focus is an inset bar + $focusRing, never colour alone.
