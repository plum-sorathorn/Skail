Dark-tech glassy HUD. Three surface depths do the work that boxes did: inset → surface → raised, so the eye reads layers instead of borders. The signature element is a lifeline spine — one gutter column inside the transcript that colours itself by whichever agent owns the row, so parallel work is legible at a glance. Budget becomes a vertical column pinned to the rail edge. Cyan is structural; violet is delegation; amber is the only thing that asks for permission. Glow is a mockup affordance — TCSS ships it as a heavy focusRing border.

Implementation notes (Textual / TCSS)

  • Layering instead of boxing. Three depths only — $surfaceInset (overlay backdrop), $surface (transcript panel), $surfaceRaised (rail, composer, chips). Never a raised panel inside a raised panel, so the “cards-in-cards” failure mode is structurally impossible.
  • Lifeline spine is one extra 3-cell column inside each transcript row (a Static with width: 3; text-align: center). Continuity comes from a 1-cell background stripe; agent ownership recolours it via $agentOne/Two/Three. Costs 3 columns, buys instant parallel-work legibility.
  • Glow is not implementable and must not be relied on: in TCSS the composer focus is border: heavy $focusRing and buttons get background: $accentSoft. The mockup’s box-shadow is decoration only.
  • Vertical budget column is a 4-cell Vertical of stacked block glyphs with 90┈ / 75┈ tick rows at the threshold cells; colour comes from budget_token_for_ratio() and the glyph count from the ratio, so the reading is never colour-dependent.
  • Segments (AGENTS/PLAN/ROUTE/BUDGET) are a TabbedContent restyled: the active tab is an inverted cell ($accent on $background) rather than an underline — readable in 16-colour terminals too.
  • Narrow mode: rail → display: none; the segment strip collapses to letters A P R B and opens a drawer overlay; the vertical meter is replaced by the horizontal pill in the command bar. The spine survives, because it is the one element that still carries agent identity when the rail is gone.
  • Approval uses border: double $approval (Textual supports double) plus $approvalSurface — the only tinted panel on screen, which is why it reads as modal without a real modal.
